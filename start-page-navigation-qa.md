# Startseitenzustand der Navigation

Die Startseite `/` wurde zusätzlich im Desktop-Header geprüft. Da die bestehende Informationsarchitektur keinen separaten Menüpunkt „Startseite“ enthält und die Startseite ausschließlich über das verlinkte Physiowerk-Logo erreichbar ist, wird dort bewusst keine hellrote aktive Pill angezeigt. Alle regulären Navigationslinks bleiben inaktiv und unverändert; der rote Kontakt-CTA behält auf der Startseite seinen bisherigen, nicht aktiven Standardzustand.
